File Organizer – Python Automation Tool

This is a simple Python-based script that helps you automatically organize your files in any selected folder. It sorts the files by file type and last modified date, placing them in neatly structured subfolders.

Features
	•	Sorts files by their extension (e.g., PDF, JPG, DOCX, etc.)
	•	Organizes files by last modified date (e.g., 2025-04-30)
	•	Creates folders automatically:
folder/type_files/date/filename
	•	Easy to use – just run the script and input the folder path
	•	Works on Windows, macOS, and Linux

How to Use
	1.	Make sure you have Python 3 installed.
	2.	Download or clone this repository.
	3.	Run the script in terminal or command prompt:
 python organizer_type_and_date_input.py

Dependencies

This script uses only built-in Python modules:
	•	os
	•	shutil
	•	datetime
